# Trade-profit bar chart examples

These images were generated through the public `analyser` API from the three
sanitized sample reports in `results/sample_reports/`. They show the default
equal-weight, capital-allocated portfolio view. The values use canonical MT5
closed-position net profit; the percentage charts use the portfolio initial
capital as their denominator.
